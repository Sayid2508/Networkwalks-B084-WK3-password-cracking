## 📌 Overview

During **Week 3**, I completed two hands-on cybersecurity projects focused on **PDF password recovery**.

The first project involved using **John the Ripper (JTR) and Johnny**, while the second focused on **Networkwalks Hash Calculator and Password Cracker**.

Through these practical exercises, I gained a better understanding of how password hashes are extracted, analyzed, and used in password recovery within a controlled laboratory environment.

These projects strengthened my practical knowledge of password security and introduced me to commonly used tools for password auditing and recovery.


---


# 🔐 Project Module 1 – John the Ripper

### Tools Used

* John the Ripper
* Johnny GUI
* Windows
* PDF Hash Extractor
* Notepad
* Password-protected PDF

### Process

1. Installed and configured John the Ripper and Johnny.
2. Extracted the password hash from the authorized PDF.
3. Saved the hash in `hash1.txt`.
4. Loaded the hash file into Johnny.
5. Started the password-recovery process.
6. Recovered the password.
7. Verified the password by opening the protected PDF.

### Result

The JTR project successfully demonstrated the workflow:

**PDF → Hash Extraction → Hash File → Johnny/JTR → Password Recovery → PDF Verification**

---

# 🌐 Project Module 2 – Networkwalks Tools

### Tools Used

* Windows laptop
* Web browser
* Networkwalks Hash Calculator
* Networkwalks Password Cracker
* Password-protected PDF

### Process

1. Opened the Networkwalks Hash Calculator.
2. Uploaded the authorized protected PDF.
3. Extracted the PDF hash.
4. Copied the complete `$pdf$` hash.
5. Pasted the hash into Networkwalks Password Cracker.
6. Started the password-recovery process.
7. Recovered the password **`password1`**.
8. Used the password to open and verify the PDF.

9. ### Result

The Networkwalks tools successfully demonstrated a browser-based password-recovery workflow without requiring local installation of JTR.
